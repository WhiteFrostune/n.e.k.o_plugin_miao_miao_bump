## 2026-11-01：连续碰撞重点交接 relay-chain-1

根据上一条原版观察纠正，撤销新版预览中“一次出手只准一次特写，后续全部全景”的约束。单次淘汰沿用已认可的 release 动作、方向与首撞时间曲线；连续淘汰转移构图重点，保持当前缩放、位置和镜头速度，约 180ms 内接到新的碰撞位置。接近地图边界、当前运动惯性不容许直接转向时，先用很短的合法减速段再转移，避免裁切造成镜头速度突变。最后一次重点保留至交接后 420ms，再用 420ms 回全景；拉远途中发生新淘汰也可从当前投影接入。100ms 内的连续事件按同组累计位置，组成共同重点；不排队重播已发生的碰撞。

共享时钟增加可接续的后续碰撞包络。后续强调保留当前真实时间、场景时间、速度和恢复斜率；平滑降到 0.35 倍、短暂保留后恢复。近同时事件不叠加包络，后续不反复重播首撞的完全停顿。场内物理、已在飞行的猫和泳圈、局部特效仍用同一场景时间，镜头仍用真实时间。这里的具体时长是本项目当前适配值，不是已测得的原作内部参数。

旧行为可用 `chain=coordinated` 对照；`chain=early/legacy` 仍保留更早方案。新版默认使用连续重点交接，仅在现有 focus/release 移动镜头下启用，其他动画选项、素材及玩法参数不变。

## 2026-11-01：连锁淘汰的镜头与停顿连续性

用户指出问题是先后淘汰时镜头／停顿节奏乱，而非单只动作方向。本轮保留新泳装、单只 release 节奏、正确飞行方向和共享场景时间。根因是首段特写结束后，晚到的淘汰仍能新建一段 gentle 镜头；原有 impactUsedThisAction 只阻止了重复停顿，没有阻止重复推镜。

## 2026-11-01：修正飞行方向与撞击方向不一致

用户认可上一轮节奏，但明确指出飞出去的方向和撞击方向对不上。本轮保留 release 时间映射、镜头参数、离场时间和全部素材，仅新增可对照的 `flight=aligned` 轨迹选项；旧入口未带此参数时保留旧方向表现，原用户对局不刷新。

根因在局部脱圈偏移：旧 slip 曲线在完全脱圈时仍有非零导数，固定向上抬升成为了后续自由飞行的永久向上速度；身体和泳圈还获得了不同的额外速度。新曲线让局部抬升／滑脱在释放点速度归零，之后自由飞行及出画方向只继承碰撞产生的运动量。纵向的局部沿撞击方向偏移与横向使用一致权重，去掉纵向 0.25 倍的不对称；已有切向速度继续保留，并非把运动目标强行投影到碰撞法线上。旋转进入自由飞行时同样从零角速度平滑衔接，避免位移修正后产生新的角速度跳变。

- 标准轨迹共 1.1 秒：前约 154 ms 短暂弹起，随后加速位移、抛物线升高、旋转与逐渐远离，末段才淡出。
- 沿致命接触双方的中心连线飞离攻击者；重合位置延用现有向外的有限方向回退。属于表现，不改变碰撞速度、伤害或攻击归属。
- 新增覆盖视口的透明画布，允许猫猫越过泳池边框。没有移动页面布局，不捕获鼠标／触摸，不参与命中检测。
- 围绕素材包围框中心旋转，兼容三个角色、新版一体泳圈、经典分体泳圈及程序绘制回退。没有删除或修改原图片。
- 实体仍在血量为零时立即移除、只计分一次。多人同时飞出；结算和返场等待现有动作与表现窗口完成。没有全局慢动作或震屏。
- 系统减少动态模式保留 0.25 秒短距离淡出，没有旋转与抛物线。正常默认尊重系统；`?motion=full` 显式预览完整效果，`?motion=reduce` 预览简化效果，仅作用于当前游戏页面。

## 复用接口

`static/motion.js` 不依赖 DOM、素材、物理对象或计时器：

- `KNOCKOUT`：正常／简化时长、起飞段和淡出段配置；对战等待时长引用同一来源。
- `createFlight(event, { spriteBox, radius, reducedMotion })`：复制事件并建立独立轨迹，不改动事件与角色数据。事件包含原点、方向、身份、可选时长；角色视觉包围框独立提供。
- `sampleFlight(track, age, map, viewport)`：根据累计有效时间返回位置、地面投影、离水高度、角度、比例和透明度。视口使用地图坐标；渲染层负责世界到屏幕的转换。省略视口时以地图世界范围为离场区域。
- `art.flightAt` 保留旧调用入口并转用轨迹模块。正式游戏直接使用轨迹实例，既有角色绘制函数可以绘制到不同画布。

未来增加猫猫可复用轨迹，替换素材及包围框即可；新地图使用自身世界尺寸。第二阶段入水应新增独立轨迹，不把返场逻辑混进击飞函数。规则事件仍由对战模块产生，绘制回调不能决定伤害／得分。
