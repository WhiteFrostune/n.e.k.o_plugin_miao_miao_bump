# 喵喵碰碰大作战

> 猫娘套泳圈，小猫满池弹。

一款为 [N.E.K.O](https://github.com/Project-N-E-K-O/N.E.K.O) 设计的猫娘泳圈碰撞小游戏。调整角度和力度，把猫猫弹出去，看她们相互碰撞、借池壁反弹，最后在水的阻力下自然停稳。

**作者：[WhiteFrostune](https://github.com/WhiteFrostune)**

**当前状态：0.1.0 碰撞手感原型已可试玩（`0.1.0.dev1`）。** 支持拖拽发射、连续碰撞、水阻和停稳；角色暂用泳圈占位，尚无血量、技能或电脑对战。暂未发布正式版本标签或安装包。

## 开始试玩

在 N.E.K.O 的插件管理器中刷新插件列表，打开本插件的「喵喵碰碰大作战」面板即可试玩；启动插件后也可点击「打开碰撞练习场」。游戏在浏览器中运行。

也可以在 N.E.K.O 仓库根目录启动独立本机预览：

```bash
uv run python -m http.server 48921 --bind 127.0.0.1 --directory plugin/plugins/miao_miao_bump
```

然后访问 [本机试玩页](http://127.0.0.1:48921/static/index.html?locale=zh-CN)。预览服务运行期间可以访问，停止后链接不再可用。

按住泳圈向后拖拽，松手发射；Esc 或右键取消。停稳后再发射。默认是三只泳圈自由练习，也可切换撞墙、对撞、连撞和墙角布局。右侧「调整手感」可以修改水阻、弹性、速度和质量。

角色沿用悠怡 PNGTuber 的大头短身、圆脸和可爱表情语言，转换成有清楚颗粒的像素美术。悠怡是独立角色，三位新角色分别设计自己的轮廓与配色。

图中为生成式概念样板，供讨论外观与配色；正式游戏精灵和动画尚未制作。参考来源见 [概念图说明](docs/art/README.md)。

## 当前原型包含

- 一个矩形水池和三个有名字、颜色区分的占位泳圈。
- 拖拽瞄准、力度提示、松手发射、取消和重置。
- 泳圈碰撞、池壁反弹、水阻衰减和自然停稳。
- 单圈撞墙、两圈对撞、三圈连撞和墙角拥挤测试布局。
- 可折叠的调参区，以及高速、缩放、页面暂停恢复等稳定性检查。

先验证“把猫猫弹出去，看她们撞来弹去”是否好玩，再接入正式美术。血量、技能、电脑对手和完整对战属于后续目标。

## 开发方式

仓库遵循 N.E.K.O 独立插件约定，仓库名为 `n.e.k.o_plugin_miao_miao_bump`，插件 ID 为 `miao_miao_bump`。

克隆到本地 N.E.K.O 源码的插件目录：

```text
N.E.K.O/plugin/plugins/miao_miao_bump/
```

在 N.E.K.O 仓库根目录运行：

```bash
git clone https://github.com/WhiteFrostune/n.e.k.o_plugin_miao_miao_bump.git plugin/plugins/miao_miao_bump
uv run neko-plugin check miao_miao_bump --strict
uv run pytest plugin/plugins/miao_miao_bump/tests -q
```

目录已经存在时，使用已有检出目录继续开发。插件通过公开 SDK 接入，默认手动启动。静态游戏面板无后端调用权限，启动插件仅注册静态页面与打开入口，不会启动后台游戏任务。

当前采用 Canvas + 本地 Matter.js 0.20.0，在浏览器内完成游戏循环；游戏页面、物理引擎和资源均保留在插件目录中，游玩时不请求外部 CDN。

代码风格检查在本插件仓库根目录运行，使用与 GitHub 相同的 Ruff 版本：

```bash
uvx ruff==0.12.4 check --ignore-noqa --config ruff.toml .
```

独立仓库中的 N.E.K.O 宿主导入按外部依赖分组；检查配置将源码根目录固定为本插件目录，避免在宿主仓库内开发时产生不同的导入分类。
