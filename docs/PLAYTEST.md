# 0.1.0 试玩与验证记录

当前版本：`0.1.0.dev1`。这是碰撞手感预览，正式角色美术、技能、血量和电脑对战未加入。

## 打开方式

### N.E.K.O 插件界面

将仓库放在 `plugin/plugins/miao_miao_bump/`，刷新插件管理器列表，进入「喵喵碰碰大作战」面板。启动插件后也会提供「打开碰撞练习场」入口。

游戏使用公开 SDK 注册静态资源；面板不需要后端动作权限。相关资源与翻译路由已通过宿主路由集成测试；用户当前主程序中的最终显示仍应按上述步骤实机确认。

### 独立本机预览

在 N.E.K.O 仓库根目录运行：

```bash
uv run python -m http.server 48921 --bind 127.0.0.1 --directory plugin/plugins/miao_miao_bump
```

打开 `http://127.0.0.1:48921/static/index.html?locale=zh-CN`。停止服务后本机链接失效。

启动目录应是整个插件目录，才能同时读取 `static/` 与 `i18n/`；直接双击 HTML 不支持加载语言文件。

## 怎么玩

1. 按住一个泳圈，向后拖拽。
2. 看方向箭头、力度条和首次接触位置，松手发射。
3. 等泳圈全部停稳，再发射任意一只。
4. Esc、右键可以取消瞄准；重置可以立即结束当前出手。
5. 切换固定布局，或在「调整手感」里改变参数。移动中暂时锁定调参。

瞄准线只提示方向与首次接触，不保证低力度能抵达该位置。先碰到池壁时，额外提示一小段反射方向，不预演后续连锁。

## 默认参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 场地 | 960 × 600 逻辑像素 | 显示缩放不改变物理尺寸 |
| 水面边界 | x：44～916，y：44～556 | 泳圈中心还需向内留出自身半径 |
| 泳圈半径 | 28 | 与实际碰撞外缘基本对应 |
| 三只质量 | 各 1 | 初始没有角色技能差异 |
| 水阻 | 0.80 /秒 | 速度按时间指数衰减 |
| 泳圈弹性 | 0.94 | 泳圈之间的反弹程度 |
| 池壁弹性 | 0.90 | 独立于泳圈弹性调节 |
| 最大发射速度 | 1600 逻辑像素/秒 | 向后拖 180 逻辑像素达到最大力度 |
| 拖拽死区 | 6 逻辑像素 | 避免轻点误发射 |
| 物理步长 | 1/240 秒 | 与显示帧率分离 |
| 停稳判定 | 全场速度低于 12，持续 0.22 秒 | 消除最后的低速微动 |

无碰撞次数上限。明显碰撞计数过滤了低速贴靠和短时间接触抖动，不代表每次物理接触都会计数。

## 参考出手

三圈连撞布局，选橘子，水平向右发射。默认参数下的定向模拟：

| 初始速度 | 明显碰撞次数 | 停稳时间 |
| --- | ---: | ---: |
| 800 | 4 | 约 4.575 秒 |
| 1100 | 5 | 约 5.579 秒 |
| 1600 | 6 | 约 5.571 秒 |

真实浏览器用鼠标拉满向右发射的结果：6 次明显碰撞，约 5.571 秒停稳。后续调参时可以用这条路线作对照；碰撞次数并不是越多越好，仍需检查方向是否清楚、等待是否舒服。

## 已完成的验证

- 11 项物理检查：发射方向与死区、半径预判、反弹与停稳、大小力度、正面与擦边、重置、质量锁定、帧率一致性、独立弹性调节、高速稳定与长帧保护。
- 高速检查覆盖四种专项布局与十二个方向，共 48 组最大允许速度场景；未发现穿墙、穿圈、持续重叠、异常加速或无法停稳。
- 30、60、144 Hz 显示节奏下，同一输入的最终位置在测试容差内一致。
- 插件生命周期注册和宿主实际静态资源／八种语言路由已通过测试。
- Chromium 实际页面验证：鼠标发射、选择、取消、重置、调参、八种语言、缩放、隐藏暂停恢复、页面清理和手机视口触摸拖拽。
- 检查期间没有浏览器脚本错误，也没有访问外部网络资源。
- 本地插件包可正常构建，资源清单和校验值检查通过；测试截图和构建输出不进入分发包。

## 当前限制与反馈重点

- 自动浏览器检查使用 Chromium；其他浏览器尚未逐一验证。
- 手机支持基础触摸，但小屏幕中的泳圈较小，当前以桌面试玩为主。
- 不模拟真实水流或软体变形；泳圈采用圆形刚体。
- 页面内参数刷新即恢复默认，不提供存档。
- 瞄准提示不包含水阻下的精确停止点。

试玩时重点反馈：拖拽是否跟手、力度是否容易掌握、撞击是否够弹、滑行是否过长或过短、最后停下是否拖沓。用户主观手感确认后，再决定调参或接入橘子的正式像素资源。
