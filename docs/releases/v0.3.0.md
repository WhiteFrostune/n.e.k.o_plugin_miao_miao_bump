# 喵喵碰碰大作战 v0.3.0

猫娘套泳圈，小猫满池弹！一款像素风三对三回合制碰撞小游戏。

## 本版更新

- **两只悠怡加入泳池。** 原皮悠怡和洛丽塔悠怡是两位独立角色。现在可以从五只猫猫中选三只出战，两只悠怡也能同时上场。
- **原皮悠怡「乘胜追击」。** 她在本轮常规出手期间淘汰敌人，就有机会再弹一次。队友接力打出的淘汰也算。
- **洛丽塔悠怡「花瓣应援」。** 她主动出手时，每次直接撞到队友，都会为对方回复等同于自己攻击力的生命值，最多回到满血。借池壁反弹后再次撞到同一位队友，也能再回一次。
- **选猫和对战演出。** 橘子、布丁和奶盖在选猫页会播放亮相和待机动画。两只悠怡在选猫页使用各自的立绘，在对局中各有开场入水、淘汰飞出和复归入水动画。
- **拖到一半可以取消发射。** 把指针拖回按下的位置附近、移出游戏画面，或拖进泳池右下角的取消区，松手就能取消。Esc 和右键也能取消，出手机会照常保留。
- **备战大厅可以换对手。** 电脑会从五只猫猫里随机选三只。点对手栏的「换一组对手」可以重抽，我方阵容和地图保持原样。

## 下载与安装

下载 [**miao_miao_bump.neko-plugin**](https://github.com/WhiteFrostune/n.e.k.o_plugin_miao_miao_bump/releases/download/v0.3.0/miao_miao_bump.neko-plugin)，在 N.E.K.O 插件管理器中导入，刷新列表并启动游戏。可用 [SHA256SUMS.txt](https://github.com/WhiteFrostune/n.e.k.o_plugin_miao_miao_bump/releases/download/v0.3.0/SHA256SUMS.txt) 核对安装包的 SHA-256 校验值。
