## 动作安排

- 受击约前三帧短促缩起、挤压泳圈，作为撞击后的反应；不预先蹲下主动跳起。
- 0.075 秒切上身伸展姿态，腿延后离开圈口；泳圈比身体晚约两帧起飞。
- 0.235 秒切收腿姿态，围绕上身重心开始转动；角色与泳圈采用不同旋转方向和弧线。
- 离场延续位移，离开可见范围后结束；没有在水面中央淡出，也没有加水花、闪光或音效来遮住动作。

头顶小猫始终包含在角色姿态里，抓紧猫娘，不作为独立飞行物。泳装、赤脚、花饰保留。三个姿态以头部锚点和统一头宽登记，避免切姿态时忽大忽小。

## 素材与复用

`poses.png` 是内置 image_gen 生成的原始透明 PNG，未裁切改写；完整提示及参考图路径在 `prompt.json`。`poses.json` 保存运行时取帧区域、头部锚点与头宽。泳圈、待机、上一版动作继续引用既有素材，均保留。

`static/knockout-action.js` 只接收原点、受击方向、尺寸、时间及视口，返回角色、泳圈、遮挡和影子的动作数据；不读取 DOM，不改血量或积分。时序集中配置，可先调节粗样，再决定正式接入。以后其他猫可沿用姿态名称和动作接口，但仍需各自的姿态图及登记数据。

这版只有三个关键姿态，是判断动作节奏的粗样；慢放中仍能看到姿态切换，尚未制作额外过渡帧。
