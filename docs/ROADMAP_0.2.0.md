# 0.2.0：动画与对战体验

沿用已认可的玩法、猫猫素材、水面和整体布局。动画基础能力可复用，触发事件、运动轨迹、角色素材与渲染分开。旧素材继续保留。

最新顺序按用户纠正执行：先完成第三阶段的普通碰撞与水面特效，再在第四阶段补齐备战、角色与地图选择及胜负结算，为未来更多角色与地图留出入口。新角色和第二张正式地图仍另行规划。

1. **淘汰撞击整体反馈**：先用橘子把受力动作、碰撞特写、慢动作及局部特效放进实际对局一起验收。接触阶段用闪光和冲击线，脱圈阶段用离水水滴与水纹，飞出阶段用短速度余迹；不再单独反复调整动作。感觉成立后再复用到另外两只猫。保留原动作与关闭强化表现的对照。不得影响即时移除实体和一次计分。橘子的节奏和方向已获认可，三猫新版泳装淘汰动作已共用接入，等待三猫实战验收；待机图与头像尚未换装。细节见 `ANIMATION_0.2.0_STAGE1.md`。
2. **返场入水（本地完成）**：三猫开场、复归动作及水花已获用户认可；血条、头像、操作提示与多猫复归、暂停、重开、最后一分的收尾检查通过。入场结束自动恢复状态，保留主动拖拽跳过入场；水纹尾段不拖慢电脑出手，见 `ANIMATION_0.2.0_STAGE2.md`。
3. **碰撞与水面反馈（收尾中）**。普通碰撞已获认可，连撞衔接已通过本地检查，用户已确认 5.5 秒水面循环第二版的观感。移动尾流可读性留在整阶段联合验收。见 `ANIMATION_0.2.0_STAGE3.md`。
4. **备战与对局 UI（本地收尾）**。已串通备战、选猫、选地图、开场、对局、结算和下一局。插件打开备战大厅，游玩版使用正式演出，试用与测试控件集中在开发验收页。见 `PREPARATION_UI_0.2.0.md`。
5. **角色特性反馈（已同步至游玩版）**。奶盖减伤、布丁撞墙回弹和橘子受撞的重量反馈已获认可。池面伤害数字已移除。
6. **整局验收与发布**：备战到结算及再次开局、连锁／同时淘汰、返场、最后一分、中途重开及常见桌面尺寸实机检查；整理 README、更新说明和可下载包，用户审核后集中发布。

第六阶段已用 Edge 跑通两局游玩版，三种特性均在对局中触发。另用受控对局核对了连锁清场换轮、三猫返场、最后一分演出及中途重开。用户已确认游玩版，0.2.0 进入本地打包与 README 审核。

音效与演出时机放到后续版本，具体版本待定。

每阶段先让用户验收，再推进下一阶段。阶段开发不自动提交或推送 GitHub，不创建正式标签或 Release。插件市场发布另行确认。

本版不安排第二张地图、新角色、模型控制或联机。
