# 喵喵碰碰大作战 v0.2.0

猫娘套泳圈，小猫满池弹！一款像素风三对三回合制碰撞小游戏。

## 本版更新

- **选好猫猫再下水。** 从备战大厅选择橘子、布丁、奶盖的出战顺序，在「开始对战」旁选地图。打完可以按原配置再开一局，也能返回备战。
- **撞飞与入水都有动画了。** 三只猫开场和返场时都会溅起水花。淘汰时猫娘与泳圈分开飞出，特写和慢动作会随连锁撞击衔接。
- **泳池会动，特性也看得见。** 水面会浮动，泳圈滑过会留下尾流。奶盖减伤、布丁撞墙回弹、橘子受撞各有独立反馈，伤害数字从池面移除。
- **对局收尾更清楚。** 换轮显示累计淘汰数，清场后直接换轮，最后一击的淘汰演出播完再进入胜负结算。

## 下载与安装

下载 [**miao_miao_bump.neko-plugin**](https://github.com/WhiteFrostune/n.e.k.o_plugin_miao_miao_bump/releases/download/v0.2.0/miao_miao_bump.neko-plugin)，在 N.E.K.O 插件管理器中导入，刷新列表并启动游戏。

[SHA256SUMS.txt](https://github.com/WhiteFrostune/n.e.k.o_plugin_miao_miao_bump/releases/download/v0.2.0/SHA256SUMS.txt) 提供安装包的 SHA-256 校验值。插件管理器需要下载区中的 `.neko-plugin` 附件。

## 验证与当前范围

已在桌面 Edge 跑通备战、对局、结算和再开一局，并单独验证连锁清场、返场、最后一分与中途重开。本版提供夏日水池和本机电脑对战，游玩无需模型、额外账号或外部网络服务。后续计划让 N.E.K.O 的猫娘参与对战。
