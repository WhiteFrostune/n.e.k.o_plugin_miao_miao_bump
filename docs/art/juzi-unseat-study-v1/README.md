## 2026-10-23 修订：先共同受击，再脱圈

用户指出第一次粗样分离过早、V 字分叉不成立。重新比对参考连续截图：接触后角色与圈先共同歪倒，随后翻转、失去支撑，最终才出现明显分离。不能把最后一帧的两侧位置当成从碰撞起就应各飞一边的轨迹。

本次仅调整独立播放器。`track-previous.js` 完整保留上一版轨迹，页面可切换“上次小样”或“修改前后同步对比”；“当前实机版”仍保留。没有替换正式对局，也没有改图或推送。

- 前 0.16 秒共享位移与旋转支点，面部锚点围绕同一圈心旋转，不提前分叉。
- 0.16–0.34 秒逐渐出现相对运动，身体翻出圈沿；圈前沿遮挡随脱圈解除，水线遮挡保留至身体离水。这些是粗样参数，不是测得的原作时序。
- 0.34 秒后延续最后接触时的水平速度与旋转速度，不再指定左右两个终点。猫娘沿撞击方向飞得更快，圈保留较多共同运动；两者不形成对称 V 字。
- 保留原四姿态与头顶小猫；尚未补画过渡帧，侧面与配饰镜像限制仍在。表现只涉及淘汰动画，不参与任何对战计算。

## 参考与适配

- 崩铁公开实录：<https://www.youtube.com/watch?v=3XPxgiLKYT4&t=63s>，约 1:03–1:05。已逐帧观察到受击歪倒、翻转脱圈、海豹与泳圈分向离场。该视频含剪辑、特效及镜头变化，不能把屏幕位移和采样时间直接当成游戏物理参数。研究记录在 `tests/artifacts/animation-reference-review-1/`。
- 樱井政博《Eight Hit Stop Techniques》：<https://www.youtube.com/watch?v=tycbMSjDDLg&t=193s>。参考命中停顿期间向受击姿态过渡的演示。本粗样只做很短的表现停顿，不改变正式物理时钟。
- Spine 官方重叠动作教学：<https://en.esotericsoftware.com/blog/Follow-through-and-overlapping-action-Animating-with-Spine-8>。用姿态中的四肢、头部、尾巴错位表达拖带；目前并没有完整骨骼或独立肢体模拟。

上述参考支持动作思路，不表示已取得或复制其素材、源码或精确时序。先侧倾失衡、沿受击方向离圈，再分开翻飞，替换此前容易读成主动起跳的姿态语言。头顶小猫与猫娘仍是同一张角色图，始终抓紧。

## 粗样限制

四个关键姿态尚未补过渡帧；不同朝向暂用镜像，因此配饰左右也会翻转。当前主要验收动作是否表达被撞失衡，不能视为最终角色动画或所有受击方向的定稿。

纯轨迹检查覆盖碰撞来向、分向轨迹、释放连续性、边沿、零方向回退与离屏前不淡出；图像检查覆盖四帧完整性及登记范围。浏览器实机截图存入忽略目录 `tests/artifacts/juzi-unseat-v1/`。
